## Featured Project

### Ocean Sentinel — GS2026

Protótipo acadêmico desenvolvido em equipe para o Global Solution 2026 da FIAP, voltado ao monitoramento de risco de acúmulo de resíduos marinhos.

A solução combina modelagem matemática e processamento em Python para calcular e classificar um Índice de Risco de Acúmulo (IRA), com uma simulação de Edge Computing (ESP32/Wokwi) representando a coleta de dados por boias.

**Minha contribuição:** lógica em Python, cálculo e classificação do IRA, e a simulação de Edge Computing/IoT.

**Tecnologias:** `Python` `C++` `ESP32` `Wokwi`
